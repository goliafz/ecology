МАСТЕРВКС 1.1.3
Надёжная запись видеоконференций: экран, два микрофона и голоса собеседников.
Разработчик: Ходаковский Александр

УСТАНОВКА (один раз)

1. Положите рядом с MasterVKS.exe модуль записи FFmpeg:
   - скачайте ffmpeg-release-essentials.zip со страницы https://www.gyan.dev/ffmpeg/builds/
   - откройте архив, зайдите в папку bin и скопируйте ffmpeg.exe в эту папку.
2. Kaspersky: добавьте эту папку в доверенные программы и разрешите MasterVKS.exe
   доступ к микрофону, если в Kaspersky включён контроль микрофона.
3. Windows: «Параметры → Конфиденциальность → Микрофон», включите доступ
   для классических приложений.
4. Запустите MasterVKS.exe, выберите экран, оба микрофона и папку для записей,
   переключите проверку на «Со звуком» и нажмите «Проверить».

В ЭТОЙ ПАПКЕ ДОЛЖНЫ ЛЕЖАТЬ

  MasterVKS.exe          программа
  MasterVKS.exe.config   настройки запуска .NET
  NAudio.Core.dll         библиотека для работы со звуком
  NAudio.Wasapi.dll       библиотека для работы со звуком
  ffmpeg.exe              модуль записи (кладёте сами, см. выше)

СОСТОЯНИЕ ПК

  В проверке есть вкладка «Состояние ПК»: питание, обновления Windows,
  процессор и память, диски, сбои Windows за 30 дней. Если строка
  «Обновления Windows» жёлтая, нажмите на неё: программа один раз
  попросит пароль администратора и запретит Windows перезагружаться
  самой. Во время записи программа предупредит, если отошла зарядка,
  процессор перегрелся или кончается память.

ЗНАЧОК НА ПАНЕЛИ ЗАДАЧ

  зелёный кружок   записи нет, всё готово
  жёлтый кружок    записи нет, проверка нашла замечания
  красный кружок   идёт запись
  красный с паузой запись на паузе

ГОРЯЧИЕ КЛАВИШИ

  Ctrl+Alt+R   начать или остановить запись
  Ctrl+Alt+P   пауза

Записи сохраняются в выбранную папку, по подпапке на каждый день.
Рядом лежат два файла: исходный MKV и MP4 для просмотра.
  без названия ВКС:  2026-10-18\2026-10-18_16-57_ВКС.mp4
  с названием:       Планёрка_2026-10-18\Планёрка_2026-10-18_16-57_ВКС.mp4

Журнал работы: %LOCALAPPDATA%\MasterVKS\logs
Подробное описание: README.md в архиве с исходным кодом.
