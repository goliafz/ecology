# План: микрофоны в Телемост через МастерВКС (не сделано, на будущее)

Задача: Телемост позволяет выбрать только один микрофон, а на столах их два
(UGREEN CM564) плюс микрофон камеры ARDOR. Нужно, чтобы собеседники слышали все.

Временное решение без доработки: Voicemeeter Banana (микрофоны в Hardware Input 1–3,
B1 включено, A1 выключено, в Телемосте «Voicemeeter Out B1»).

## Как встроить в МастерВКС

1. Виртуальный микрофон: бесплатный драйвер VB-Cable (ставится один раз).
   Программа выводит звук в «CABLE Input», в Телемосте выбирается «CABLE Output».
   Свой драйвер не делаем: нужна подпись Microsoft.
2. Сведение для Телемоста из AudioEngine: смесь по Дугану (как в RoomMixer).
   По желанию (галочка) подавление эха от телевизора по звуку компьютера: это
   может помочь, если эхо Телемоста не справляется с задержкой ТВ по HDMI.
3. Вывод через WasapiOut (общий режим, низкая задержка), кольцевой буфер с
   подстройкой хода часов, как во входном джиттер-буфере.
4. Работает всё время, пока открыта программа (ВКС начинается раньше записи).
   Пропавший микрофон подхватывается сам.
5. Строка проверки «Микрофоны в Телемост»: неслышный сигнал в CABLE Input,
   слушаем CABLE Output. Нет драйвера — подсказка, где взять.
6. Предупреждение при закрытии программы: у Телемоста пропадёт микрофон.
7. Задержка 20–40 мс.
