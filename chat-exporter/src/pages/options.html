Сохранение файлов

Chrome разрешает расширениям сохранять файлы только внутри папки загрузок (можно с подпапками). Если в Chrome включено «Всегда указывать место для скачивания», он будет спрашивать путь для каждого файла — для автоматического режима это нужно отключить (chrome://settings/downloads).

Пример

С %date% в имени файла каждый день получается отдельный файл, и в папке чата складывается хронология по датам. Новый файл появляется, только если переписка изменилась или вы экспортируете чат вручную. Папка запоминается при первом сохранении: после переименования чата файлы продолжат складываться туда же. Если у двух чатов одинаковое название, ко второй папке добавляется начало идентификатора.

Автоматическое резервное копирование

Работает только пока запущен Chrome. Если в назначенное время браузер закрыт или компьютер спит, запуск выполняется по правилу ниже при следующем запуске браузера.

Какие чаты сохранять
Дни недели (пусто = каждый день)
Форматы
Если запуск пропущен

Помеченные чаты

Чаты с галочкой «Сохранять». Их отслеживает автоматический режим: при изменениях в папку чата добавляется файл с датой. Чаты хранятся по идентификатору, поэтому переименование не мешает. Значок расширения на вкладке такого чата — зелёный, на остальных чатах — красный.

Исключённые чаты

Используется в режиме «Все чаты»: исключённые чаты не участвуют в автоматическом копировании. Добавить можно на странице «Список чатов».

Журнал операций

Журнал хранится только в этом браузере и содержит названия чатов и статусы, без текста переписок.

Данные расширения

После очистки расширение будет считать все чаты несохранёнными. Файлы на диске не удаляются.
