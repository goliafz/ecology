Сохранение файлов

Chrome разрешает расширениям сохранять файлы только внутри папки загрузок (можно с подпапками). Абсолютные пути недоступны. Если в настройках Chrome включено «Всегда указывать место для скачивания», Chrome будет спрашивать путь для каждого файла — для автоматического режима это нужно отключить (chrome://settings/downloads).

Переменные: {service} {title} {id} {shortId} {date} {time}. В папке всегда есть уникальный id, иначе чаты с одинаковыми названиями смешались бы. Папка чата фиксируется при первом экспорте, поэтому переименование чата не создаёт вторую папку.
