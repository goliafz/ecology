# Chat Exporter — ChatGPT & Claude

**Разработчик: Ходаковский Александр**

Расширение Chrome (Manifest V3) для сохранения переписок ChatGPT и Claude в **PDF, HTML и
Markdown**. Проверяет полноту выгрузки и умеет автоматически копировать изменившиеся чаты по
расписанию, пока запущен браузер. Работает локально: содержимое переписок никуда не отправляется.

- Экспорт текущего чата, выбранных чатов или всех изменившихся.
- Длинные диалоги без прокрутки: данные берутся из того же источника, что использует сам сайт,
  во вкладке, где вы уже вошли в аккаунт. Если источник недоступен, включается резервный режим
  с прокруткой страницы и склейкой фрагментов.
- Проверка полноты: непрерывная цепочка сообщений, сверка со страницей, признак генерации ответа,
  отчёт в `*.meta.json` и в самом документе.
- Автоматический режим: расписание, отметки активности, догоняющий запуск, повторы, журнал.

Подробности: [архитектура и анализ](docs/ARCHITECTURE.md) · [план тестирования](docs/TESTING.md).

## Установка (без сборки)

1. Скачайте `chat-exporter-1.2.0.zip` и распакуйте **в постоянную папку** (Chrome загружает
   расширение из неё при каждом запуске). Можно использовать и папку `chat-exporter/` из репозитория.
2. Откройте `chrome://extensions`.
3. Включите **«Режим разработчика»** (справа вверху).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку с `manifest.json`.
5. Закрепите значок Chat Exporter на панели (значок пазла → булавка).
6. Обновите уже открытые вкладки ChatGPT и Claude (или расширение подключится к ним само при
   первом экспорте).
7. Для автоматического режима отключите в `chrome://settings/downloads` настройку **«Всегда
   указывать место для скачивания»**, иначе Chrome будет спрашивать путь для каждого файла.

Требуется Chrome 120 или новее.

**Обновление с предыдущей версии:** распакуйте новый архив поверх старой папки и нажмите
«Обновить» (круговая стрелка) у расширения в `chrome://extensions`. Настройки сохранятся. Форматы
версии 1.0.0 (HTML + Markdown) заменятся на PDF, потому что раньше они не выбирались явно.

## Сборка и проверка (для разработки)

```bash
cd chat-exporter
npm install            # только инструменты разработки: TypeScript, jsdom, типы chrome, marked
npm run typecheck      # проверка JSDoc-типов
npm test               # юнит-тесты (node:test)
npm run package        # dist/chat-exporter-<версия>.zip — только файлы для браузера (нужна утилита zip)
npm run vendor         # обновить src/vendor/marked.esm.js из node_modules
# E2E (нужен Playwright с Chromium; на Linux без экрана — через xvfb-run):
xvfb-run -a npm run e2e
xvfb-run -a npm run e2e:pdf   # PDF в настоящей фоновой вкладке (без эмуляции фокуса Playwright)
```

Сборка кода не нужна: расширение — это обычные ES-модули.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `host_permissions`: chatgpt.com, chat.openai.com, claude.ai | Content script во вкладках сервисов, внедрение в уже открытые вкладки, чтение URL активной вкладки |
| `storage` | Настройки, индекс экспортов, очередь, расписание, журнал |
| `alarms` | Расписание автоматического копирования и отложенные повторы |
| `downloads` | Сохранение файлов в папку «Загрузки» |
| `offscreen` | Создание blob-ссылок для сохранения (в service worker это невозможно) |
| `scripting` | Подключение к вкладкам, открытым до установки расширения |
| `debugger` | Автоматическая генерация PDF (`Page.printToPDF`) **только для страницы самого расширения** |

О `debugger`. Chrome не позволяет сделать это разрешение необязательным. При установке оно
показывает предупреждение о доступе к данным, а во время генерации PDF появляется полоса
«Chat Exporter начало отладку этого браузера». Если это неприемлемо, удалите `"debugger"` из
`manifest.json`, перезагрузите расширение и выберите в настройках «PDF через окно печати».
Расширение само определит, что разрешения нет. HTML и Markdown работают без него.

Чего расширение **не** делает: не запрашивает пароли, не хранит токены, не отправляет данные
сторонним серверам, не загружает внешние скрипты. Сохранённые HTML-файлы содержат
Content-Security-Policy, которая запрещает скрипты и любые сетевые загрузки.

## Использование

**Окно расширения (popup):**
- «Экспорт текущего чата» — чат в активной вкладке, в отмеченных форматах (сохраняет всегда).
- «Выбрать чаты» — страница со списком чатов: поиск, фильтры («изменены после сохранения»,
  «ни разу не сохранены», «ошибки и неполные»), исключение из авто-режима.
- «Экспортировать выбранные» — очередь, по одному чату, с прогрессом.
- Переключатель «Автоматический режим» и кнопка «Сохранить изменившиеся чаты сейчас».
- Прогресс, кнопка отмены, результат и предупреждения; баннер о пропущенном запуске.

**Форматы** задаются только в настройках (по умолчанию — только PDF). Окно расширения
показывает текущий формат и ссылку «изменить».

**Где лежат файлы** (по умолчанию: папка `ChatBackups`, маска папки `%name%`, маска файла
`%name%_%date%`):

```
Загрузки/
  ChatBackups/
    Показ промта улучшателя/
      Показ промта улучшателя_2026-10-22.pdf
      Показ промта улучшателя_2026-10-24.pdf     ← хронология: новый файл в каждый день с изменениями
    План проекта/
      План проекта_2026-10-24.pdf
```

Подстановки в масках:

| Подстановка | Значение |
|---|---|
| `%name%` | название чата |
| `%date%` | дата сохранения, ГГГГ-ММ-ДД |
| `%time%` | время сохранения, ЧЧ-ММ |
| `%updated%` | дата последнего изменения чата, ГГГГ-ММ-ДД |
| `%service%` | ChatGPT или Claude |
| `%id%`, `%shortId%` | идентификатор чата целиком / первые 8 символов |

Примеры: `%service%/%name%` — отдельные папки для ChatGPT и Claude; пустая маска папки — все
файлы в одной папке; `%date%_%time% %name%` — несколько версий в день. В настройках показывается
пример итогового пути.

- Новый файл появляется, только если переписка изменилась (или при ручном экспорте). Если файл с
  таким именем уже есть (тот же день), он заменяется; можно выбрать «сохранить рядом с номером».
- Папка запоминается при первом сохранении: после переименования чата файлы складываются туда же.
  Если у двух чатов одинаковое название, к папке второго добавляется начало идентификатора.
- Служебный файл `.meta.json` (отчёт о полноте, контрольные суммы) по умолчанию **не пишется**;
  его можно включить в настройках. Проверка целостности на диске работает только с ним:
  `node tools/verify-backups.mjs ~/Downloads/ChatBackups`.
- Неполный ручной экспорт сохраняется с суффиксом `_НЕПОЛНЫЙ`.
- Хранить копии в другом месте можно двумя способами: перенести папку загрузок Chrome или
  сделать символическую ссылку `Загрузки/ChatBackups` на нужную папку.

**Если экспорт получился неправильным**, откройте этот чат и нажмите в окне расширения «Данные
для диагностики». Исходные данные чата сохранятся в `ChatBackups/_diagnostics/<сервис>_<id>.json`.
Файл содержит текст переписки; по нему можно понять, какой формат сообщения не распознан.

## Помеченные чаты («Сохранять»)

Автоматически сохраняются только помеченные чаты (так настроено по умолчанию).

- Откройте чат ChatGPT или Claude, нажмите на значок расширения и включите **«Сохранять»**.
- Значок расширения на вкладке чата: **зелёный** — чат помечен, **красный** — не помечен, синий —
  открыт не чат. У каждой вкладки свой значок, в том числе у закреплённых.
- Расширение ведёт базу помеченных чатов по **идентификатору** чата из адреса (`/c/<id>` у ChatGPT,
  `/chat/<id>` у Claude). Переименование чата пометку не сбрасывает, название в базе обновляется само.
- База видна в Настройки → «Помеченные чаты», там же можно снять пометку. Пометить или снять
  пометку можно и на странице «Выбрать чаты» (колонка «Сохранять»).
- Только что помеченный чат сохраняется при ближайшем автоматическом запуске, даже если давно не
  менялся. Дальше — только когда в нём появились изменения: в папку чата добавляется файл с датой.
- Отслеживаются ChatGPT и Claude одновременно, в том числе в закреплённых вкладках.
- Режим «все изменившиеся чаты» по-прежнему доступен в настройках.

## Настройка автоматического копирования

1. Включите переключатель «Автоматически сохранять» в окне расширения или в Настройки →
   «Автоматическое резервное копирование»: время (например 23:00), дни недели (пусто — каждый
   день), какие чаты сохранять (по умолчанию — помеченные), форматы.
2. «Если запуск пропущен»: **спросить** (по умолчанию), **выполнить автоматически** через
   2 минуты после старта браузера или **пропустить**.
3. Лимит чатов за запуск, пауза между чатами (по умолчанию 2,5 с), число попыток.
4. «Открывать вкладку сервиса в фоне» — если вкладка ChatGPT/Claude закрыта, расширение откроет
   её неактивной и закроет после работы. Вы должны оставаться в аккаунте.
5. Сохранить. Включить и выключить режим можно и переключателем в окне расширения.

Как это работает:
- В назначенное время расширение получает **список чатов** со временем изменения, не открывая
  каждый чат. В очередь попадают помеченные чаты, изменённые после прошлого сохранения, ещё ни разу
  не сохранённые, а также неполные и временно неудачные экспорты. Если помеченных чатов какого-то
  сервиса нет, его список даже не запрашивается.
- В режиме «все изменившиеся чаты» сразу после включения сохраняются только чаты, изменённые после
  включения; старые — флажком «Постепенно сохранить и старые чаты».
- Неизменившиеся чаты не перезаписываются: сравнивается хеш содержимого.
- **Ограничение:** если в назначенное время Chrome закрыт, компьютер выключен или спит, запуск не
  происходит. Он будет обработан при следующем старте Chrome по выбранному правилу.

## Структура проекта

```
chat-exporter/
  manifest.json
  icons/                      иконки (tools/make-icons.py)
  src/
    background/               service worker: роутер, очередь, расписание, экспорт, загрузки, PDF
    content/                  content script: клиенты данных ChatGPT/Claude, DOM-резерв, трекер активности
    adapters/                 нормализация данных каждого сервиса + реестр сервисов
    core/                     модель, проверка полноты, Markdown/HTML, имена файлов, хеши, расписание
    offscreen/                offscreen-документ для blob-ссылок
    pages/                    popup, настройки, выбор чатов, страница печати
    vendor/marked.esm.js      Markdown-парсер (MIT)
  tests/                      юнит-тесты, фикстуры, e2e
  tools/                      упаковка, проверка бэкапов, обновление vendor, иконки
  docs/                       архитектура, тестирование
```

## Известные ограничения

| Ограничение | Почему | Что сделать |
|---|---|---|
| Внутренние эндпоинты ChatGPT и Claude не документированы | Публичного API истории веб-чатов нет | При ошибке формата включается резервный DOM-режим; обновить адаптер в `src/adapters/` и `src/content/*-client.js` |
| Селекторы DOM-режима для ChatGPT обновлены по снимку реальной страницы (октябрь 2026): сообщения пользователя находятся, для ответов модели формат атрибутов предполагается по аналогии | Вёрстка меняется | Если сверка со страницей или резервный режим перестанут работать — прислать «Данные для диагностики»: в них есть снимок структуры страницы |
| Без запущенного Chrome копирование не выполняется | Ограничение браузерных расширений | Догоняющий запуск при старте |
| Файлы сохраняются только внутри «Загрузок» | Ограничение `chrome.downloads` | Перенос папки загрузок или символическая ссылка |
| Оригиналы вложений (PDF, документы) не сохраняются | Расширение получает только описание файла или извлечённый текст | Скачивать оригиналы в сервисе |
| Картинки по подписанным ссылкам на чужом домене могут не встроиться (CORS) | Политика безопасности браузера | Пометка в документе, статус «с предупреждениями» |
| Ответы в незнакомом формате | Сервисы добавляют новые типы сообщений и метаданных (так было с блоками кода-виджетами ChatGPT, исправлено в 1.1.1) | Текст сохраняется в исходном виде с пометкой; если извлечь нечего, экспорт помечается «НЕПОЛНЫЙ». Пришлите файл «Данные для диагностики» |
| Экспортируется видимая ветка (после правок и перегенераций) | Так работает интерфейс; альтернативы отмечаются числом | Переключить вариант на сайте и экспортировать снова (режим «версии») |
| Чаты из проектов ChatGPT получаются отдельным запросом **[предположение]** | Они не входят в основной список | При ошибке — предупреждение в журнале; список считается неполным |
| Формулы (LaTeX) сохраняются как исходный текст | Нет рендерера формул без внешних скриптов | Читать в Markdown-редакторе с поддержкой LaTeX |
| Временные чаты ChatGPT не поддерживаются | У них нет id в адресе, и они не входят в историю | — |
| PDF требует разрешения `debugger` и показывает полосу отладки | Правила Chrome | Режим «окно печати» |
| Linux с не-UTF-8 локалью: кириллица в путях | Chrome не может преобразовать имя | Автоматическая транслитерация пути |
