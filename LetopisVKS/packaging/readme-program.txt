ЛЕТОПИСЬ ВКС 1.0
Надёжная запись видеоконференций: экран, два микрофона и голоса собеседников.
Разработчик: Александр Ходаковский

УСТАНОВКА (один раз)

1. Положите рядом с LetopisVKS.exe модуль записи FFmpeg:
   - скачайте ffmpeg-release-essentials.zip со страницы https://www.gyan.dev/ffmpeg/builds/
   - откройте архив, зайдите в папку bin и скопируйте ffmpeg.exe в эту папку.
2. Kaspersky: добавьте эту папку в доверенные программы и разрешите LetopisVKS.exe
   доступ к микрофону, если в Kaspersky включён контроль микрофона.
3. Windows: «Параметры → Конфиденциальность → Микрофон», включите доступ
   для классических приложений.
4. Запустите LetopisVKS.exe, выберите экран, оба микрофона и папку для записей,
   переключите проверку на «Со звуком» и нажмите «Проверить».

В ЭТОЙ ПАПКЕ ДОЛЖНЫ ЛЕЖАТЬ

  LetopisVKS.exe          программа
  LetopisVKS.exe.config   настройки запуска .NET
  NAudio.Core.dll         библиотека для работы со звуком
  NAudio.Wasapi.dll       библиотека для работы со звуком
  ffmpeg.exe              модуль записи (кладёте сами, см. выше)

ЗНАЧОК НА ПАНЕЛИ ЗАДАЧ

  зелёный кружок   записи нет, всё готово
  жёлтый кружок    записи нет, проверка нашла замечания
  красный кружок   идёт запись
  красный с паузой запись на паузе

ГОРЯЧИЕ КЛАВИШИ

  Ctrl+Alt+R   начать или остановить запись
  Ctrl+Alt+P   пауза

Записи сохраняются в выбранную папку, по подпапке на каждый день,
например «2026-10-18\2026-10-18_14-30_ВКС.mp4».

Журнал работы: %LOCALAPPDATA%\LetopisVKS\logs
Подробное описание: README.md в архиве с исходным кодом.
