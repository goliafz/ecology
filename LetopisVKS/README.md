# Летопись ВКС

Программа для Windows 10 и 11, которая надёжно записывает видеоконференции: весь экран, два микрофона и голоса собеседников.

Разработчик: **Александр Ходаковский**.

## Что умеет

* Пишет весь экран в исходном разрешении, без уменьшения. Сжатие визуально без потерь (H.264, CRF 18).
* Одновременно пишет оба микрофона (например, USB-микрофон и микрофон камеры) и звук компьютера, то есть голоса участников из Телемоста.
* В файле четыре звуковые дорожки: общая («Все вместе»), «Микрофон 1», «Микрофон 2» и «Звук собеседников». Если в общей дорожке что-то не так, нужный источник можно послушать отдельно (например, в VLC: «Аудио → Аудиодорожка»).
* Проверяет оборудование при каждом запуске и по кнопке «Проверить». Режимов два:
  * **Тихая** проверка: ничего не звучит, звук компьютера проверяется неслышным сигналом;
  * **Со звуком**: звучит короткая мелодия, и программа проверяет, что её услышали оба микрофона.
* Показывает результат проверки по пунктам: модуль записи, экран, микрофон 1, микрофон 2, звук собеседников, оба микрофона вместе (разрывы звука, гул и наводки, эхо), место на диске. Нажмите на строку, чтобы прочитать подробности и совет.
* Значок на панели задач: **зелёный** кружок, когда записи нет и всё готово; **жёлтый**, когда проверка нашла проблемы; **красный**, когда идёт запись (с жёлтой обводкой, если во время записи что-то отвалилось). На паузе красный кружок с двумя полосками.
* Предупреждает, если места на диске осталось меньше чем на 2 часа записи.
* Пауза, горячие клавиши (Ctrl+Alt+R начинает или останавливает запись, Ctrl+Alt+P ставит паузу), подтверждение остановки, автозапуск вместе с Windows (включается в настройках).

## Как программа защищает запись

* **Запись идёт в MKV.** Этот формат читается даже после внезапного выключения или синего экрана. Каждые 2 секунды программа просит Windows сбросить файл на диск, поэтому при аварии теряются максимум последние секунды. После остановки из MKV без пересжатия делается обычный MP4. Если длительность MP4 совпала с исходником, MKV удаляется, чтобы не занимать место дважды (это можно отключить в настройках).
* **Незавершённые записи доделываются сами.** Если программа или Windows упали во время записи, при следующем запуске программа найдёт оборванный файл и сделает из него MP4.
* **Микрофон выдернули?** Запись продолжается. Вместо пропавшего микрофона пишется тишина, а когда устройство вернётся (даже в другой USB-порт), звук подхватится сам.
* **Звук ушёл на телевизор по HDMI?** Если в «Звуке собеседников» выбрано «Как в Windows», программа сама переключится на новое устройство вывода.
* **Модуль записи упал или завис?** Сторож перезапускает его за пару секунд и пишет дальше в следующую часть, а после остановки части склеиваются в один MP4.
* **Изменилось разрешение экрана** (например, подключили телевизор)? Картинка вписывается в исходный размер, запись не прерывается.
* **Картинка и звук не расходятся** даже на многочасовой записи: оба потока идут по одним часам, а разница хода часов у звуковых устройств выравнивается незаметно, по одному сэмплу.
* Пока идёт запись, ноутбук не уснёт и не погасит экран, а Windows 11 не переведёт программу в «режим эффективности».
* Подробный журнал работы лежит в `%LOCALAPPDATA%\LetopisVKS\logs`.

## Установка

1. Нужен .NET Framework 4.8. В Windows 10 (с 2019 года) и Windows 11 он уже есть.
2. Распакуйте папку `Программа` из архива в любое место, например в `C:\Летопись ВКС`.
3. **Положите рядом модуль записи FFmpeg** (один раз):
   * скачайте `ffmpeg-release-essentials.zip` со страницы <https://www.gyan.dev/ffmpeg/builds/>;
   * откройте архив, зайдите в папку `bin` и скопируйте `ffmpeg.exe` в папку с `LetopisVKS.exe`.
4. Запустите `LetopisVKS.exe`.
5. **Kaspersky.** Добавьте папку программы в доверенные (Настройки → Исключения → Доверенные программы). Если в Kaspersky включён контроль доступа к микрофону, разрешите его для `LetopisVKS.exe`. Иначе микрофон может присылать тишину, и проверка это покажет.
6. **Доступ к микрофону в Windows:** «Параметры → Конфиденциальность → Микрофон», включите «Разрешить классическим приложениям доступ к микрофону».

## Перед первой записью

1. Выберите экран (если телевизор подключён в режиме «Повторять», экран будет один).
2. Выберите «Микрофон 1» (USB) и «Микрофон 2» (камера).
3. В «Звуке собеседников» оставьте «Как в Windows». Если в Телемосте выбран конкретный динамик, укажите здесь его же.
4. Выберите папку для записей.
5. Переключите проверку на «Со звуком» и нажмите «Проверить». Должны позеленеть все строки.

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| «Не найден FFmpeg» | Положите `ffmpeg.exe` рядом с программой (см. «Установка») |
| Микрофон «присылает полную тишину» | Разрешите доступ к микрофону в Windows и в Kaspersky, проверьте кнопку отключения на микрофоне |
| «Звук прерывается» | Подключите микрофон и камеру в разные USB-порты ноутбука, без разветвителя |
| «Слышен гул 50 Гц» | Наводка от HDMI, зарядки или удлинителя: попробуйте другой порт или работу от батареи |
| «Проверочная мелодия не записалась» | Проверьте, что звук Windows не выключен и в «Звуке собеседников» выбрано правильное устройство |
| В общей дорожке эхо | Это микрофоны слышат собеседников из динамиков. Отдельные дорожки чистые; в настройках можно убрать лишний источник из общей дорожки |
| «Компьютер не успевает сжимать видео» | В настройках снизьте плавность до 25 кадров в секунду |

## Исходный код

```
src/LetopisVKS/          программа (C#, WinForms, .NET Framework 4.8)
  Core/                  настройки, журнал, часы, системные функции Windows
  Video/                 захват экрана (GDI, Per-Monitor DPI) и поток кадров
  Audio/                 захват звука (WASAPI через NAudio), сведение, проверочный сигнал
  Recording/             запись через FFmpeg, сторож, MKV → MP4, восстановление
  Checks/                проверка оборудования и анализ звука
  UI/                    окно программы, настройки, значки панели задач
tests/LetopisVKS.SelfTest/   автотесты логики (.NET 8, запускаются на любой ОС с ffmpeg)
```

Как устроена запись: программа сама снимает экран и звук и по двум именованным каналам (named pipes) отдаёт ffmpeg.exe сырые кадры и шесть каналов звука. FFmpeg сжимает видео в H.264, звук в AAC и пишет MKV. Номер кадра и номер звукового сэмпла считаются по одним часам, поэтому синхронизация не зависит от того, успевает ли компьютер.

### Сборка

Нужен .NET SDK 6 или новее (или Visual Studio 2019/2022 с .NET Framework 4.8):

```
dotnet build src/LetopisVKS/LetopisVKS.csproj -c Release
```

Готовая программа появится в `src/LetopisVKS/bin/Release/`. Рядом с `LetopisVKS.exe` должны лежать `NAudio.Core.dll`, `NAudio.Wasapi.dll` и `LetopisVKS.exe.config`.

Автотесты:

```
cd tests/LetopisVKS.SelfTest
dotnet run -c Release
```

## Сторонние компоненты

* [NAudio](https://github.com/naudio/NAudio) 2.2.1 (лицензия MIT): работа со звуковыми устройствами Windows.
* [FFmpeg](https://ffmpeg.org) (лицензия GPL для сборки essentials): сжатие видео и звука. Не входит в архив, скачивается отдельно.
