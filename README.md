# Экология-сервис — сайт

Новая главная страница для [eco-service27.ru](https://eco-service27.ru) — ООО «Экология-сервис», региональный оператор по обращению с ТКО в зоне № 2 Хабаровского края.

## Структура

```
index.html            — главная страница
assets/css/style.css  — стили (адаптив: компьютер, планшет, телефон)
assets/js/main.js     — меню, вкладки, анимация появления, форма обращения
assets/img/logo.svg   — логотип и иконка сайта
```

Сборка не нужна: достаточно открыть `index.html` в браузере или загрузить файлы на хостинг.

## Разделы главной

1. Первый экран — кто мы, кнопки «Оплатить» и «Заключить договор», быстрые действия и телефон.
2. Услуги — шесть частых вопросов (оплата, договор, тарифы, перерасчёт, КГО, жалоба на вывоз).
3. Как мы работаем — путь отходов в четыре шага.
4. Договор — отдельные инструкции для жителей и для организаций и ИП.
5. Оплата — приложение ВЦ, онлайн-банк, банк или почта.
6. Памятка — что можно и что нельзя выбрасывать в контейнер.
7. Частые вопросы.
8. Новости — ссылки на материалы текущего сайта.
9. Контакты и форма обращения.

## Что нужно уточнить перед запуском

- Форма обращения пока открывает почтовую программу с готовым письмом на info@eco-service27.ru. Чтобы заявки приходили автоматически, нужен обработчик на сервере (например, PHP-скрипт или CRM).
- Часы работы офиса, номер кабинета и ссылки на приложение ВЦ (App Store / Google Play) — добавить, когда будут точные данные.
- Размер тарифа и перечень обслуживаемых районов зоны № 2.
- Ссылка на политику обработки персональных данных для формы.
