# WL Tester — тестер белых списков и VPN для Android

Разработчик: **Ходаковский Александр**

Приложение работает в фоне и по расписанию проверяет мобильный интернет:
- открываются ли российские и зарубежные сайты;
- работает ли VPN (VLESS Reality, как в Marzban/NekoBox).

Всё записывается в подробный журнал. По нему видно, когда оператор включает белые списки, когда отключает, на каком этапе режутся соединения и что может помочь их обойти.

## Установка

1. Откройте на телефоне страницу **Releases** этого репозитория и скачайте последний `WL-Tester-1.0.N.apk`.
2. Установите его, разрешив установку из этого источника.
3. Новые версии ставятся поверх старой, журнал сохраняется.

APK собирается автоматически через GitHub Actions (workflow `WL Tester — сборка APK`). Его также можно скачать из артефактов сборки.

## Настройка (один раз)

1. **Настройки → VPN-профили.** Вставьте ссылки `vless://…` из подписки Marzban, по одной в строке. Ссылки хранятся только на телефоне.
2. **Когда проверять:**
   - *По времени (окно)*, например 00:00–07:00. Вне окна приложение спит.
   - *Постоянно — следить за VPN.* Раз в N минут делается быстрая проверка VPN. Если VPN не работает 2 раза подряд (повтор через минуту), включаются полные проверки, пока VPN не вернётся.
3. **Частота:**
   - «Экономия батареи» — раз в 15 и 30 мин;
   - «Сбалансированный» — 5 и 15 мин;
   - «Подробный» — 2 и 5 мин;
   - «Свой» — интервалы вручную.

   Под списком показан примерный расход трафика.
4. **Статус:** уберите все предупреждения:
   - отключите оптимизацию батареи;
   - разрешите уведомления;
   - по желанию разрешите доступ к состоянию телефона, чтобы в журнал писался тип сети 4G/5G.

   На Xiaomi, Huawei и Samsung дополнительно разрешите автозапуск и работу в фоне без ограничений.
5. **Выключите Wi-Fi.** Проверки идут только через мобильный интернет. Если Wi-Fi включён, проверка пропускается и приходит напоминание.
6. Включите **Мониторинг**.

NekoBox не мешает, если тестер не добавлен в список приложений, идущих через VPN. Если трафик тестера всё же пойдёт через VPN, приложение предупредит об этом.

## Что проверяется в полном цикле

| Группа | Что именно |
|---|---|
| РФ напрямую | yandex.ru, ya.ru, vk.ru, vk.com, ok.ru, gosuslugi.ru, ozon.ru, mail.ru, sberbank.ru, tbank.ru, avito.ru, wildberries.ru, rutube.ru, dzen.ru, max.ru, mos.ru, nalog.gov.ru, 2gis.ru, kinopoisk.ru, rbc.ru и сайты российских хостингов |
| Зарубежные напрямую | google.ru, google.com, wikipedia.org, github.com, cloudflare.com, 1.1.1.1 (голый IP), apple.com, microsoft.com, amazon.com |
| Сервер VPN напрямую | DNS, TCP к каждому порту, TLS с каждым SNI (SNI-матрица: SNI профилей + ya.ru), ping |
| Через VPN (каждый профиль) | generate_204, внешний IP, youtube.com, telegram.org, web.telegram.org, whatsapp.com, instagram.com, google.com, chatgpt.com |
| DNS | UDP-запросы к 8.8.8.8, 1.1.1.1, 77.88.8.8 |
| Загрузка | файл с российского CDN и с Cloudflare (напрямую и через VPN). Выявляет «заморозку» соединения после ~16 КБ |

Каждая HTTPS-проверка разбита на этапы: DNS → TCP → TLS → HTTP. Для каждого этапа записываются время и тип ошибки (таймаут, сброс, отказ и т.д.). Все списки сайтов можно редактировать.

Для теста VPN приложение запускает ядро Xray-core как отдельный процесс с локальным SOCKS-входом на каждый профиль. VPN-интерфейс при этом не поднимается, поэтому NekoBox не мешает.

## Журнал и выводы

- **Журнал:** все циклы по дням. Нажатие на цикл открывает каждую проверку с этапами и ошибками.
- **События:** включение и отключение белых списков (с точностью «между 01:05 и 01:10»), пропадание и возврат VPN, смена сети.
- **Отчёт:**
  - хронология состояния сети и VPN;
  - время включения и отключения белых списков по ночам;
  - таблица доступности «норма | белые списки»;
  - автоматические выводы: блокировка по IP или по SNI, «заморозка» после ~16 КБ, какой профиль работал, какие российские хостинги доступны ночью (кандидаты для промежуточного сервера).
- **Сохранить ZIP / Поделиться:**
  - `report.txt`;
  - `cycles.csv`, `checks.csv`, `events.csv` (разделитель `;`, открываются в Excel);
  - исходные `jsonl`.

## Сборка вручную

```bash
cd vpn-whitelist-tester
./gradlew -PcoreOnly=true :core:test   # тесты логики, без Android SDK
bash scripts/fetch-xray.sh             # скачать ядро Xray (по умолчанию v25.8.3, XRAY_VERSION=... для другой)
./gradlew :app:assembleRelease         # нужен Android SDK (ANDROID_HOME)
```

Структура:
- `core/` — чистый Kotlin/JVM: пробы, разбор `vless://`, конфиг Xray, анализ, отчёт, CSV. Покрыт тестами.
- `app/` — Android:
  - служба переднего плана и будильники AlarmManager;
  - запуск Xray;
  - журнал;
  - интерфейс на Jetpack Compose.

**Подпись.** APK подписывается ключом `signing/wltester.jks`. Он лежит в репозитории, чтобы любая сборка ставилась поверх предыдущей. Чтобы подписывать своим ключом, задайте переменные окружения `WL_KEYSTORE_FILE`, `WL_KEYSTORE_PASSWORD`, `WL_KEY_ALIAS` и `WL_KEY_PASSWORD`, например через секреты GitHub Actions. После смены ключа приложение придётся один раз переустановить.
